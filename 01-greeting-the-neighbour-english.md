# Καλημέρα γειτόνισσα — Good Morning, Neighbour

|                | Κυπριακά                                                                   | English                                                                          |
| -------------- | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Κυρία Μαρούλλα | Καλημέρα γιε μου!                                                          | Good morning, my son!                                                            |
| Νίκος          | Καλημέρα κυρία Μαρούλλα. Ίνταλως είσαστε;                                  | Good morning, Mrs Maroulla. How are you?                                         |
| Κυρία Μαρούλλα | Καλά, δόξα τω Θεώ. Εσού; Ίντα κάμνεις;                                     | Fine, thank God. And you? How are you doing?                                     |
| Νίκος          | Καλά είμαι, ευχαριστώ. Νάκκον κουρασμένος.                                 | I'm fine, thanks. A bit tired.                                                   |
| Κυρία Μαρούλλα | Γιατί; Εν εκοιμήθηκες καλά;                                                | Why? Didn't you sleep well?                                                      |
| Νίκος          | Όι, έκαμνε πολλή ζέστη ψες.                                                | No, it was very hot last night.                                                  |
| Κυρία Μαρούλλα | Ε ναι, έτσι έν το καλοτζαίρι δαμαί. Έσιεις κλιματιστικό;                   | Well yes, that's summer here. Do you have air conditioning?                      |
| Νίκος          | Έσιει, αμμά εν δουλεύκει καλά.                                             | There is one, but it doesn't work well.                                          |
| Κυρία Μαρούλλα | Να πεις του ιδιοκτήτη να το φτιάξει. Εν γίνεται να κοιμάσαι μες στη ζέστη. | Tell the landlord to fix it. You can't sleep in that heat.                       |
| Νίκος          | Ναι, εννά του πάρω τηλέφωνο σήμμερα.                                       | Yes, I'll call him today.                                                        |
| Κυρία Μαρούλλα | Πού πάεις τωρά; Δουλειά;                                                   | Where are you going now? Work?                                                   |
| Νίκος          | Ναι, ξεκινώ στες οχτώ.                                                     | Yes, I start at eight.                                                           |
| Κυρία Μαρούλλα | Άτε, να μεν αρκήσεις.                                                      | Go on, don't be late.                                                            |
| Νίκος          | Όι, έχω ώρα κόμα.                                                          | No, I still have time.                                                           |
| Κυρία Μαρούλλα | Το απόγευμα έλα που το σπίτι για καφέ. Εννά κάμω τζιαι γλυκό.              | Come over to the house for coffee this afternoon. I'll make something sweet too. |
| Νίκος          | Ευχαριστώ πολλά! Ίντα ώρα να έρτω;                                         | Thank you very much! What time should I come?                                    |
| Κυρία Μαρούλλα | Στες έξι. Εν καλά;                                                         | At six. Is that OK?                                                              |
| Νίκος          | Πολλά καλά. Εννά έρτω.                                                     | Very good. I'll come.                                                            |
| Κυρία Μαρούλλα | Άτε, στο καλό γιε μου.                                                     | Off you go, take care, my son.                                                   |
| Νίκος          | Γεια σας! Τα λαλούμεν το απόγευμα.                                         | Bye! See you this afternoon.                                                     |
