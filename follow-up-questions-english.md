# Για να μεν σταματά η κουβέντα — Keep the Conversation Going

## Τζιαι μετά; — Keep the Story Going

| Κυπριακά                | English                     |
| ----------------------- | --------------------------- |
| Τζιαι μετά;             | And then?                   |
| Τζιαι ίντα έγινε;       | And what happened?          |
| Τζιαι ίντα είπε;        | And what did he/she say?    |
| Τζιαι εσού ίντα έκαμες; | And what did you do?        |
| Πε μου πκιο πολλά.      | Tell me more.               |
| Τζιαι πώς τελείωσε;     | And how did it end?         |
| Σοβαρά; Τζιαι ύστερα;   | Seriously? And after that?  |
| Τζιαι ίνταλως το πήρε;  | And how did he/she take it? |

## Ενδιαφέρον — Show Interest

| Κυπριακά                   | English                        |
| -------------------------- | ------------------------------ |
| Έλα, πε μου!               | Go on, tell me!                |
| Αλήθκεια; Εν το ήξερα.     | Really? I didn't know that.    |
| Μα ίντα λαλείς!            | You're kidding!                |
| Ωραίο ακούεται.            | Sounds nice.                   |
| Κρίμα, λυπούμαι.           | What a pity, I'm sorry.        |
| Μπράβο, χαίρομαι για σένα. | Well done, I'm happy for you.  |
| Ε, καλά έκαμες.            | Well, you did the right thing. |
| Εν σε αδικώ.               | I don't blame you.             |
| Έτσι έν;                   | Is that so?                    |
| Τζιαι ήτουν ωραία;         | And was it nice?               |

## Λεπτομέρειες — Ask for Details

| Κυπριακά                     | English                     |
| ---------------------------- | --------------------------- |
| Ίντα ακριβώς έγινε;          | What exactly happened?      |
| Πότε έγινε τούτο;            | When did this happen?       |
| Πού ήτουν;                   | Where was it?               |
| Με ποιον επήες;              | Who did you go with?        |
| Πόσην ώρα εκάτσετε;          | How long did you stay?      |
| Ίντα ώρα ήρτετε πίσω;        | What time did you get back? |
| Πόσο σου εκόστισε;           | How much did it cost you?   |
| Πώς επήες, με το αυτοκίνητο; | How did you go, by car?     |
| Ποιος άλλος ήτουν τζιαμαί;   | Who else was there?         |

## Τζιαι εσού; — Turn It Back to Them

| Κυπριακά                         | English                                |
| -------------------------------- | -------------------------------------- |
| Τζιαι εσού;                      | And you?                               |
| Εσού ίντα κάμνεις συνήθως;       | What do you usually do?                |
| Σου αρέσκει τούτο;               | Do you like that?                      |
| Που ποιο χωρκό είσαι;            | Which village are you from?            |
| Πόσον καιρό δουλεύκεις τζιαμαί;  | How long have you worked there?        |
| Έσιεις χόμπι;                    | Do you have any hobbies?               |
| Ίντα κάμνεις τα Σαββατοκύριακα;  | What do you do at weekends?            |
| Πού επήες διακοπές φέτος;        | Where did you go on holiday this year? |
| Ποιο φαΐ σου αρέσκει πκιο πολλά; | Which food do you like most?           |

## Γνώμη — Ask for an Opinion

| Κυπριακά                | English                   |
| ----------------------- | ------------------------- |
| Ίνταλως σου φάνηκε;     | How did you find it?      |
| Ίντα λαλείς εσού;       | What do you think?        |
| Άρεσε σου;              | Did you like it?          |
| Έν καλύτερα έτσι;       | Isn't it better this way? |
| Εσού ίντα εννά έκαμνες; | What would you do?        |
| Αξίζει;                 | Is it worth it?           |
| Εννά το ξανάκαμνες;     | Would you do it again?    |
| Το συστήνεις;           | Do you recommend it?      |

## Συναισθήματα — Feelings

| Κυπριακά            | English               |
| ------------------- | --------------------- |
| Ίνταλως ένιωσες;    | How did you feel?     |
| Εφοήθηκες;          | Were you scared?      |
| Χάρηκες;            | Were you happy?       |
| Εθύμωσες;           | Did you get angry?    |
| Κουράστηκες;        | Did you get tired?    |
| Έν ούλλα καλά τωρά; | Is everything OK now? |

## Άλλο θέμα — Change the Topic

| Κυπριακά                               | English                            |
| -------------------------------------- | ---------------------------------- |
| Αλλά πε μου...                         | But tell me...                     |
| Μιας τζιαι λαλούμεν για...             | Since we're talking about...       |
| Άσ' το τούτο, ίντα νέα που τη δουλειά; | Forget that, what's new at work?   |
| Θυμάσαι τότε που...;                   | Do you remember that time when...? |
| Να σου πω τζιαι κάτι άλλο;             | Can I tell you something else?     |

## Κλείσιμο — Wrap Up

| Κυπριακά                          | English                        |
| --------------------------------- | ------------------------------ |
| Τέλος καλό, ούλλα καλά.           | All's well that ends well.     |
| Πρέπει να το ξανακάμουμεν.        | We should do it again.         |
| Πε μου ίντα έγινε μετά.           | Let me know what happens next. |
| Πάρε με να μου πεις.              | Call me and tell me.           |
| Τα λαλούμεν πκιο πολλά άλλη φορά. | We'll talk more another time.  |
